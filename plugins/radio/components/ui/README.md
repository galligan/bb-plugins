# BB controls

These controls and overlay helpers are vendored from the public `@bb` registry at `get-bb/bb` tag `desktop-v0.49.0`, matching Radio's BB0.49.0 / SDK0.6.132 pins. `components.json` retains that registry. Add only the required recipes and their support files. The utility module retains only `cn`, which these controls use; the unrelated path display helper is omitted. Keep responsive overlays, portal scope and pointer sizing helpers together. Domain panel code lives separately in `components/radio`.
